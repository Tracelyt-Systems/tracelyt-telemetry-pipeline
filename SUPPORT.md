# Getting Support for Tracelyt Telemetry Pipeline

Thank you for your interest in the Tracelyt Telemetry Pipeline component.

## Community and Discussion

This repository serves as the telemetry processing engine foundation for the Tracelyt platform. Because this repository is currently in its initial architecture and scaffolding phase:

1. **Architecture & Engineering Discussions**: Open a GitHub Discussion under the [Tracelyt-Systems Discussions](https://github.com/orgs/Tracelyt-Systems/discussions) area if enabled, or file an issue using the appropriate template.
2. **Defects & Build Issues**: If you identify a bug in the repository setup, build configuration, or documentation, please submit a report using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
3. **Feature Proposals**: If you wish to propose architectural extensions or new processing capabilities, please open an issue using the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).

## Security Inquiries

If you suspect a vulnerability in the project foundation, Docker image configuration, or dependencies, do **not** file a public issue. Follow the coordinated disclosure instructions in [SECURITY.md](SECURITY.md).

## Response Expectations

Tracelyt is an open-source community maintained by distributed engineers. Maintainers review issues and pull requests during development cycles. Response times may vary depending on project milestones and maintainer availability.
