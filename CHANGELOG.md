# Changelog

All notable changes to the Tracelyt Telemetry Pipeline will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added
- Initial project foundation and architectural documentation.
- Java 21 LTS and Spring Boot 3.4.3 build configuration with Maven wrapper.
- Static analysis configuration via Checkstyle with zero violations.
- Security baseline: threat modeling, data privacy, and supply chain controls.
- Operational planning: capacity planning, observability, and configuration strategy.
- Automated CI workflow for build verification, test execution, and static checks.
- Open-source governance files: Contributing guide, Code of Conduct, Security policy, Support, and Codeowners.

> **Note**: Telemetry processing, stream routing, Kafka connectors, and storage integrations are intentionally not implemented in this initial foundation release.
